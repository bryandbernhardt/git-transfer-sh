# Constituição do projeto

## Stack
- Shell script puro
- Compatível com Linux, Windows e MacOS
- Testes com ShellSpec

## Arquitetura
- O script não deve precisar de dependências externas, sendo possível executá-lo em qualquer sistema operacional apenas executando o script

## Qualidade
- Toda lógica precisa ter teste unitário para validar os diferentes caminhos do código

## Convenções
- Todo código deve ser em inglês
- Commit no formato: tipo(escopo): descrição, com o identificador do requisito

## Governança
- Se o plano contradiz a constituição, quem muda é o plano
- Se a constituição precisa mudar, muda em commit separado
